# C++11 面向对象重构实施说明

## 1. 实施结论

本工程以 `C++11面向对象重构详细设计方案.md` 为依据进行渐进式等价重构。外部入口、JSON 字段、状态枚举、算法参数、候选顺序、车道边线启用状态和几何约束语义保持兼容。

重构采用兼容门面过渡：新模块位于 `src/api`、`src/domain`、`src/preprocessing`、`src/ordering`、`src/generation`、`src/constraints` 和 `src/io`；原有 `intersection_shape_generator.h` 继续作为兼容头。

## 4. 明确保留的基线行为

- `EdgeLineGenerator` 顶层调用仍关闭，`IntersectionOutput::lane_edges` 默认保持为空。
- 生成会话仅使用 `GenerationPlanner` 生成稳定批次；无调用的旧 `GlobalCoordinator` 和空软障碍接口已删除。
- 普通曲线、U 型、固有形态、Boundary、Fence、Obstacle、同簇和 G1 的现有算法参数保持不变。
- 固有形态保留原始 Z；其他曲线按首尾 lane 端点 Z 沿弧长插值。
- C++ 标准保持 C++11。

## 5. 等价实现边界

`FixedShapeInitializer` 保持退化折线段跳过规则；`OrdinaryCurveInitializer` 保持 alpha 枚举顺序和 G1 切向回退；`UTurnCurveInitializer` 保持单段对齐弧与首直/中弧/尾直三段式表达；`AvoidanceCandidateGenerator` 负责 Waypoint 表达。U-turn 多约束、Boundary 和 Obstacle 绕行仍使用原有固定网格、阈值与提前退出次序；Boundary 贴附候选等不可达历史分支已删除，现行搜索生命周期收口在单条流水线和修复协调器内。

专用搜索不强制套用单一加权选择器：有界 U-turn、Boundary 和 Obstacle 各自保留已验证的业务词典序；可严格映射为结构化键的生产循环使用 `CandidateSelector`。这是为保证候选集合和最终选择与基线一致，而不是保留第二套公共实现。

## 6. 构建与验收

```bash
cmake -S . -B cmake-build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build cmake-build-debug -j2
ctest --test-dir cmake-build-debug --output-on-failure
```

依赖下载不可用时，可先验证核心库：

```bash
cmake -S . -B cmake-build-core -DINTERSECTION_BUILD_TESTS=OFF
cmake --build cmake-build-core -j2
```

约束或曲线生成代码发生变化时，除模块测试外，至少运行 `test_intersection_input_regression` 中相关标签，并覆盖普通曲线、U 型、Boundary、Obstacle、Fence、同簇和 fixed geometry 的交互场景。代表性单路口应保持毫秒级，任何单路口不得超过 15 秒。
